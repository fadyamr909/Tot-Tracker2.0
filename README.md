# 👶 Tot-Tracker 2.0

### Smart Baby Monitoring Mobile App

**Tot-Tracker 2.0** is a Flutter-based mobile application that helps modern parents monitor and track their baby’s daily activities in a smart and organized way.  
The app provides a simple, intuitive interface for logging and viewing data such as feeding times, sleep duration, diaper changes, and more — all in one place.

Originally designed as a graduation project, Tot-Tracker aims to evolve into a complete solution that integrates **AI analysis** and **IoT devices** in future versions.

---

## 🚀 Features

- 🍼 **Activity Tracking** — Record baby activities like feeding, sleeping, and diaper changes  
- 📊 **Daily & Weekly Reports** — View summaries and charts of baby care routines  
- 📱 **Cross-Platform** — Built with Flutter to run on both Android and iOS  
- ☁️ **Firebase Integration** — For authentication and real-time database storage  
- 👨‍👩‍👧 **Multi-User Access** — Allow both parents to view and update the same baby profile
